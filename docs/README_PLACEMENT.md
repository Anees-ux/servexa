# Servexa Canonical Project Documents

These are the current essential approved/reference documents for starting the Servexa repository.

## Desktop setup

Create:

Desktop/
└── Servexa/
    └── docs/

Copy the contents of this package into `Servexa/docs/` so the final structure is:

Servexa/
└── docs/
    ├── 01-domain/
    ├── 02-product/
    ├── 03-ux/
    ├── 04-domain-validation/
    ├── 05-architecture/
    └── 06-data/

Do not rename individual canonical documents unless the architecture baseline is deliberately versioned later.
